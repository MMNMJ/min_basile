# 민-바실 부숑 / Min-Basile Bouchon — v0.4

Arduino 코드 → 안전 우선 축약 → 7-bit ASCII → 원형 타공 → SVG / 벡터 PDF.
기존 연속 배치에 **7-bit Column Layout / 문자 세로열 배치**를 추가했습니다. 기본 모드는 문자 세로열 배치이며, 기존 연속 배치도 설정창에서 선택할 수 있습니다. 벡터 PDF 출력도 추가했습니다.

## 실행하기

1. ZIP 파일을 **모두 압축 해제**합니다.
2. 폴더 안의 `index.html`을 Chrome 또는 Edge로 엽니다.
3. Arduino 코드를 붙여 넣고 **교정**을 눌러 결과를 확인합니다.
4. **변환**을 눌러 판형·여백·원을 설정한 뒤 **적용 · 변환**을 누릅니다.
5. **출력 · SVG / PDF**에서 형식을 선택해 다운로드합니다. 둘 다 선택할 수 있습니다. 브라우저에서 여러 파일 다운로드 허용이 필요할 수 있습니다.

Python, Flask, Node.js 설치나 서버 실행이 필요 없습니다. 인터넷 없이 사용할 수 있고 코드가 외부에 전송되지 않습니다. `core.js`, `app.js`를 `index.html`과 같은 폴더에 두세요.

저장 위치는 브라우저의 다운로드 설정을 따릅니다. 일반적으로 다운로드 폴더에 저장되며, 브라우저가 저장 위치를 묻도록 설정되어 있으면 선택창이 나옵니다. 웹앱이 컴퓨터의 특정 폴더에 강제로 저장하지는 않습니다.

### 7-bit Column Layout

한 문자는 세로 7비트 한 열입니다. ASCII의 상위 비트부터 위에서 아래로 읽습니다. `A`는 `1000001`이므로 같은 x좌표의 맨 위와 맨 아래에 원이 생깁니다. 0도 비트 자리는 차지하지만 출력 객체는 생성하지 않습니다. 문자 14개를 한 행 그룹에 놓고, 15번째 문자는 다음 그룹의 첫 열로 이동합니다. Characters per row는 사용자가 변경할 수 있습니다.

열 중심 간격의 자동값은 `(width - left - right) / charactersPerRow`입니다. 마지막 그룹에 문자가 적어도 기존 열 위치를 유지합니다.

행 그룹 자동 간격은 코드의 전체 그룹 수를 기준으로 내부 높이를 균등하게 사용합니다. 한 그룹뿐이면 위쪽에 배치합니다. 비트 중심 간격이나 원 크기를 자동으로 줄이지 않으며, 그룹이 들어가지 않으면 경고하고 출력을 생성하지 않습니다.

```
outerDiameter = circleDiameter + strokeWidth
halfOuter = outerDiameter / 2
innerHeight = boardHeight - topMargin - bottomMargin
groupHeight = 6 * bitPitch + outerDiameter
groups = ceil(characterCount / charactersPerRow)

columnPitch(auto) = innerWidth / charactersPerRow
occupiedHeight = 6 * bitPitch + halfOuter
rowGroupPitch(auto, groups > 1) = (innerHeight - occupiedHeight) / (groups - 1)
rowGroupPitch(auto, groups = 1) = 7 * bitPitch

column = charIndex % charactersPerRow
rowGroup = floor(charIndex / charactersPerRow)
x = leftMargin + columnPitch / 2 + column * columnPitch
y = topMargin + rowGroup * rowGroupPitch + bitIndex * bitPitch
```

v0.3에서는 요청한 좌표식을 그대로 사용합니다. **세로열 모드의 topMargin은 첫 비트 중심 위치**입니다. 첫 원의 위쪽 반지름과 선 두께 절반은 위 여백 영역에 걸칩니다. 원이 판형 밖으로 나가지 않도록 topMargin의 최소값을 검사합니다. 나머지 방향은 원 바깥 경계가 설정 영역을 넘지 않도록 검사합니다. 연속 모드의 여백 계산은 기존 그대로입니다.

**직접 입력** 옵션의 열 간격은 문자 열 중심 사이 거리, 행 그룹 간격은 그룹의 첫 비트 중심에서 다음 그룹의 첫 비트 중심까지의 거리입니다. 모두 mm 단위입니다. 행 그룹 사이 실제 빈 공간은 `rowGroupPitch - groupHeight`입니다. 자동값은 설정창과 변환 후 미리보기 아래에 표시합니다. 직접 입력 기본값은 열 약 17.7143 mm, 행 그룹 35 mm입니다.

원 또는 그룹이 겹치거나 설정한 배치 범위를 넘는 경우 경고합니다. 열 수와 원 크기를 유지할 수 없는 판형으로는 출력하지 않습니다. 마지막 문자에 0만 있어도 그 문자 전체 공간을 검사합니다.

### Continuous Bit Layout

기존 배치 계산을 유지했습니다. 전체 비트열을 왼쪽 → 오른쪽, 위 → 아래로 채웁니다. 한 문자의 7비트가 행 경계에서 나뉠 수 있습니다.

이 모드의 가로·세로 빈 간격은 기존과 같이 각각 0.75 mm이며, 중심 간 거리는 원 지름 + 빈 간격입니다. 설정창에서 모드를 바꿔도 현재 판형·여백·원 설정을 그대로 사용합니다. 이전 기본 배치와 동일한 결과가 필요하면 여백을 각각 20 mm로 설정하세요.

가로 피치 = 지름 + 가로 빈 간격

열 수 = floor((내부 가로폭 − 지름 − 선 두께) / 가로 피치) + 1

세로도 같은 방식으로 계산합니다. 자동 축소·분할·잘라내기는 하지 않습니다.

## 코드 교정의 범위

- 원본 입력은 그대로 보존하고 교정 결과를 별도 창에 표시합니다.
- 변환 버튼도 현재 원본을 다시 교정하므로 오래된 결과를 변환하지 않습니다.
- 문자열·문자 리터럴·raw 문자열 안의 공백과 주석처럼 보이는 문자를 보존합니다.
- `#include`와 줄바꿈을 보존합니다. 전처리문은 일반 코드처럼 한 줄로 합치지 않습니다.
- 연산자나 식별자가 달라질 수 있는 공백은 삭제하지 않습니다.
- 헤더에서 정의된 함수형 매크로가 인자를 문자열로 만들 수 있으므로 괄호 안의 기존 공백은 보수적으로 유지합니다.
- `#define`, 조건부 전처리문, `__LINE__` 등이 있으면 주석을 제거하되 나머지 공백·줄바꿈은 보존합니다. 따라서 어떤 코드는 한 줄로 축약되지 않습니다.
- 역슬래시로 여러 줄을 연결한 코드와 트라이그래프는 오류를 표시하고 교정을 중단합니다. 원본은 바꾸지 않습니다.
- 문법 오류를 추측해서 수정하거나 누락된 세미콜론을 자동으로 추가하지 않습니다.

**이 앱은 Arduino 컴파일러가 아닙니다.** 보드 종류·라이브러리·Arduino 전처리 환경에 따른 실행 가능성은 교정된 코드를 Arduino IDE에 붙여 넣어 컴파일해 확인하세요. 축약 전 코드가 잘못되었다면 축약으로 실행 가능한 코드가 되는 것은 아닙니다.

## ASCII의 정확성

교정된 코드의 모든 문자를 7비트로 변환합니다. 보존된 공백, 줄바꿈(LF = 0001010), 탭도 문자 수와 비트 수에 포함합니다. 일반적인 CRLF 줄바꿈은 교정 단계에서 LF로 정리합니다.

한글 주석은 교정 시 제거됩니다. 문자열이나 식별자에 한글·이모지 등 비ASCII 문자가 남아 있으면 해당 문자와 행을 알리고 변환을 중단합니다. 데이터를 삭제하거나 UTF-8로 몰래 바꾸지 않습니다. UTF-8 모드는 추후 확장 대상입니다.

## SVG / PDF 출력과 Illustrator

- SVG의 width/height는 mm, viewBox는 같은 수치로 작성합니다.
- 1에 해당하는 `<circle>`만 생성합니다.
- `fill="none"`, RGB 선 색상, 설정한 mm 선 두께를 유지합니다.
- 판형 외곽선·여백 표시·0 가이드·문자 수·캡션은 출력에 포함하지 않습니다. v0.4의 SVG 전용 구분선은 별도 출력 설정을 따릅니다.
- PDF도 동일한 타공 좌표를 사용하고, 채움 없는 원형 벡터 경로로 출력합니다. PDF 형식의 내부 단위는 pt이므로 72/25.4 변환을 적용해 실제 판형과 선 두께를 mm로 유지합니다. 원은 PDF 표준 방식인 4개 3차 베지어 곡선으로 표현합니다.
- 미리보기만 선을 굵게 보여줍니다. 다운로드한 SVG의 선 두께는 기본 0.01 mm입니다.
- Illustrator에서 SVG를 열고 아트보드 치수와 원 지름을 확인할 수 있습니다. 실제 Illustrator 실행 검증이나 레이저커팅 실물 테스트는 아직 수행하지 않았습니다.
- SVG는 RGB를 사용합니다. CMYK 분판이나 제작소 전용 색상 지정은 이번 단계에 포함하지 않습니다. 제작소별 절단선 인식 조건은 전달 전에 확인하세요.

파일명 예: `Min_Basile_Bouchon_2026-09-18_103000_Arduino_ASCII_300x450_column.svg` 또는 `.pdf`
날짜와 시간은 사용자의 컴퓨터 현지 시각입니다.

## 작품 설명

〈민-바실 부숑〉은 Arduino 실행 코드를 7-bit ASCII로 변환하고, 그 비트값을 레이저커팅 가능한 타공 패턴으로 번역하는 프로그램이다. 이 프로그램은 IBM식 천공카드의 행정적 분류 체계보다, 바실 부숑의 직조 제어 장치에서 출발한 구멍-패턴-노동의 계보를 참조한다.

Min-Basile Bouchon is a code-to-punch-pattern converter. It transforms executable Arduino sketches into 7-bit ASCII, then translates binary values into laser-cuttable holes.

## v0.3 문자와 실제 타공의 대조

교정 버튼 또는 변환 버튼을 누르면 미리보기 앞에 **index / original character / ASCII decimal / 7-bit binary** 테이블을 표시합니다. 이 테이블의 문자는 원본에서 교정된 코드의 실제 문자입니다. 주석 제거 이전 원문 인덱스가 아닙니다. 인덱스는 0부터 시작하며, 100문자씩 이전/다음으로 전체를 확인할 수 있습니다. 공백과 줄바꿈도 한 문자로 포함되고 표시 이름만 알아보기 쉽게 바뀝니다.

| index | original character | ASCII decimal | 7-bit binary |
|---|---|---|---|
| 0 | v | 118 | 1110110 |
| 1 | o | 111 | 1101111 |
| 2 | i | 105 | 1101001 |
| 3 | d | 100 | 1100100 |

코드가 `void`로 시작할 때 위 값이 표시됩니다. 기본 서보 예제는 `#include`로 시작하므로 첫 문자는 `#`입니다.

세로열 생성은 문자별 반복 안에서 0~6번째 비트를 검사합니다. x는 문자 인덱스로만 계산하고, bitIndex는 y에만 사용합니다. 미리보기 및 SVG/PDF 생성 전에 문자 ASCII와 타공 좌표를 다시 비교하며, 불일치하면 생성을 중단합니다. 0 가이드를 켠 경우에도 같은 좌표를 사용하지만 출력에는 포함하지 않습니다.

기존 가로 비트열 텍스트는 숫자 확인용이며 타공 배치 방향을 뜻하지 않습니다. 실제 배치 모드는 미리보기 바로 위에 표시합니다. v0.3의 기본값은 7-bit Column Layout이고, Continuous Bit Layout은 사용자가 선택할 수 있도록 유지합니다.

v0.3 테스트는 `void`의 실제 SVG 원 좌표를 독립적인 기대값과 대조하고, x좌표 불변·15번째 문자 줄바꿈·공백과 줄바꿈 문자 보존을 확인합니다. 좌표나 디버그 값을 일부러 훼손했을 때 SVG/PDF 출력이 차단되는지도 검사합니다. 브라우저 UI 직접 조작 검증은 아직 완료하지 않았습니다.

## v0.4 — SVG 전용 가로 구분선

기존 교정·ASCII·배치·미리보기·PDF를 그대로 유지하고 SVG 전용 편집 구분선만 추가했습니다.

1. 코드를 변환합니다.
2. **출력 · SVG / PDF**를 누릅니다.
3. SVG 및 7-bit Column Layout에서 **SVG에 가로 구분선 포함**을 설정합니다(기본 ON).
4. 색상·선 두께·길이·가로 이동·세로 이동을 설정하고 저장합니다.

| 설정 | 기본값 |
|---|---|
| 색상 | 회색 #999999 |
| 선 두께 | 0.1 mm |
| 길이 | 판형 가로 − 왼쪽 여백 − 오른쪽 여백 |
| 가로 / 세로 이동 | 각각 0 mm, 음수 허용 |
| 시작 x | 왼쪽 여백 + 가로 이동 |

길이는 새 변환 결과를 출력할 때 그 판형의 내부 가로폭으로 초기화합니다. 다른 구분선 설정은 페이지를 새로고침하기 전까지 유지됩니다.

**한 7비트 그룹마다 선 하나**를 생성합니다. 14문자이면 1개, 15문자이면 2개이며 마지막 미완성 그룹도 포함합니다. 문자가 0비트만 가져도 같은 7비트 영역을 기준으로 계산합니다. charactersPerRow 변경도 반영됩니다.

그룹 사이 선은 위 그룹 마지막 비트 원의 외곽과 아래 그룹 첫 비트 원의 외곽 사이 중앙입니다. 마지막 그룹은 마지막 비트 원 외곽 아래 2 mm입니다. 원 외곽에는 선 두께를 포함합니다. 세로 이동은 이 기본값에 더합니다. 구분선 두께까지 포함하여 그룹 영역과 겹치거나 판형을 벗어나면 경고하고 저장을 중단합니다. 자동으로 타공을 이동·축소하거나 선을 생략하지 않습니다. 구분선 OFF 또는 PDF만 선택하면 구분선 설정 오류는 출력에 영향을 주지 않습니다.

SVG에는 `<g id="row-group-separators">`를 별도 그룹으로 만들고, `row-separator-1` 등 고유 ID의 `<line>`을 넣습니다. fill은 none이며 mm 좌표를 사용합니다. Illustrator에서 그룹 또는 개별 선을 선택해 편집·삭제할 수 있습니다. PDF 및 프로그램의 타공 미리보기에는 구분선이 없습니다. Continuous Bit Layout에서는 이 기능이 비활성화됩니다.

**SVG 구분선은 편집용입니다. 이 SVG를 레이저커팅에 사용할 때는 구분선을 삭제하거나 절단 제외로 지정하세요.** 별도 그룹이나 회색이라는 이유만으로 자동 절단 제외되지 않습니다.
